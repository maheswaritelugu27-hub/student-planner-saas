# Student Planner SaaS — StudyFlow

A responsive student study planner built with HTML, CSS, and JavaScript.

## Features
- Create study tasks with date, time, duration, subject, and priority
- Filter tasks by all, pending, or completed
- Track daily tasks, completed work, planned study hours, and weekly progress
- Set a daily task goal
- 25-minute focus timer
- Light and dark themes
- Saves tasks and preferences in browser LocalStorage
- Responsive layout for desktop, tablet, and mobile

## Run locally
Open `index.html` in a modern web browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your `student-planner-saas` repository.
2. On GitHub, open **Settings → Pages**.
3. Under the build and deployment section, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. After deployment, your site should be available at:
   `https://maheswaritelugu27-hub.github.io/student-planner-saas/`

Tasks are saved in the current browser only; this demo does not include a server, user accounts, or cloud sync.
